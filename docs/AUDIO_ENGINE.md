# Audio engine

MOSS plays everything — the pond, the overworld, the motifs and the interface
sounds — through **one coordinated scheduler** on the DMG's four channels.
Nothing is pre-recorded. There is no PCM playback and no software mixing.

Source: `source/audio.c`, `source/audio.h` (home bank), tables generated by
`tools/gen_audio_tables.py`.

## The four voices

| Voice | Channel | Role | Typical settings |
| --- | --- | --- | --- |
| A — Pebbles | 1, pulse with sweep | player notes, melodic phrases, bell lilies, motifs | duty 50 %, start volume 8–13, hardware decay; pebble "plip" uses an upward sweep (NR10 0x16) |
| B — Living sounds | 2, pulse | insect chirps and replies, reed lilies, echo repeats, UI | duty 12.5 % trills (retriggered every 3 frames, quieter each time); reeds at 25 % with vibrato |
| C — The water | 3, wave | sustained drone, harmonic movement, root (bass) lilies | four 32-step wave patterns: Soft (sine), Hollow (odd harmonics), Warm (rounded saw), Reed (soft pulse) |
| D — The environment | 4, noise | rain drops, wind gusts, creek babble, wood knocks, clock | 15-bit noise for weather; 7-bit (tonal) mode for wood and the clock |

These roles are defaults. Echo repeats of channel-1 notes are played on
channel 2 and vice versa (a ping-pong delay across the two pulses), so a
repeat never cuts off the note it repeats.

## Scheduling

```
composer (main loop, bank 1) --snd_play(event, delay)--> 24-entry queue
                                                         |
timer interrupt, 60.24 Hz -------------------------------+--> APU registers
```

- **The only code that writes sound registers is the timer interrupt**
  (`audio_isr`), so the composer, the story's motifs and UI sounds can never
  overwrite each other's registers mid-update.
- The interrupt runs from the **timer** (4096 Hz / 68 = 60.24 Hz), not
  VBlank. An early build ran audio in VBlank; its handler could outlast the
  VBlank window and the LCD-off wait missed it. Moving audio to the timer
  keeps VBlank free for display work.
- Each queued event carries an absolute tick (`at`). The interrupt keeps the
  earliest due time, so on most ticks it does one comparison and returns; it
  only scans the queue when something is due.
- The composer **schedules ahead** by up to 8 ticks, so a main-loop stall
  (loading a map with the LCD off, a save) of less than ~130 ms does not move
  any note. Longer stalls are absorbed by skipping, never by bursting: if the
  composer falls more than 24 ticks behind it re-synchronises (SILT's rule).
- If the queue is full, the lowest-priority pending event is replaced, or
  the new event is dropped if nothing pending is less important.

## Channel ownership and priority

Every event has a priority (ambient 1, echo 2, music 3, player 5, motif 6,
UI 7) and a `hold` time in ticks during which it owns its channel. A new
event takes a busy channel only if its priority is at least the owner's. When
the hold expires anyone may use it. A drone never blocks other events; a
root-lily note on channel 3 temporarily *accents* the drone instead of
replacing it.

## Click-free techniques used

- Pulse and noise notes are fire-and-forget with **hardware envelopes**.
  Volume is never changed mid-note through NRx2 (avoids DMG "zombie mode").
- Vibrato, slides and the drone's **portamento** write only NRx3/NRx4 without
  the trigger bit, which changes pitch without restarting the waveform.
- The drone's level changes use NR32 (100/50/25 %), which needs no retrigger.
- Before rewriting wave RAM, channel 3's DAC is switched off (NR30 = 0). This
  avoids the DMG wave-RAM corruption bug on retrigger; it can produce a tiny
  click, so it happens only when a different wave is needed or the drone
  starts.
- Fades between scenes use NR50 master volume or release envelopes
  (`snd_flush`), not DAC switching, for the pulse channels.

## Pitch

`note_period[]` covers MIDI 36–107 for the pulse channels
(f = 131072 / (2048 − x)). Channel 3 is an octave lower for the same register
value, so the engine adds 12 before looking up a wave note. Notes outside the
table are clamped.

## Stereo

NR51 panning is hard left / centre / right per channel. Pond columns 0–2 pan
left, 5–7 right; echoes alternate sides. Settings → Sound: Mono disables
panning.

## Interface sounds

`sfx_blip`, `sfx_confirm`, `sfx_page` and `sfx_step_stone` are short events at
UI priority on channels 2 and 4, so they briefly take precedence and then hand
the channel back.

## Motifs (authored)

Short phrases live in `compose.c` (`motif_deg`, `motif_gap`) as scale degrees,
so they follow the current scale:

| Motif | Heard | Notes (D minor) |
| --- | --- | --- |
| POND | the first pebble; every discovery | A C D A |
| BELL | the station bell | D then A (a fifth) |
| MAE | the radio, the notebook scene | F G A G F D |
| IRIS | meeting Iris | D C A C D |
| TRAIN | Mr Vale's memory | C A, slow, with vibrato |
| CHIME | Mae's wind chime | D A, an octave up |
| ANSWER | the hidden path, the pond's answer | D A G D A |

Each motif heard in the world is added to the pond's phrase memory, which is
how music heard in the overworld reappears at the pond. These motifs are new
material written for MOSS; SILT has no authored melodies to quote.
