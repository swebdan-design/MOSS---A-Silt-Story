# Controls

## Walking

| Button | Action |
| --- | --- |
| + pad | Walk. Tapping a new direction turns on the spot. |
| A | Talk, look at the thing in front of you, confirm |
| B | Cancel / back. Hold A or B to hurry text. |
| START | Menu: Notebook, Save, Settings, Controls, Title screen, Close |
| SELECT | Open the Sound Notebook |
| (nothing) | **Stand still to listen.** After about 1.3 s (Quick) or 2.5 s (Patient) a small ring appears above the boy, the melody steps back, and anything there is to hear in that spot happens. |

## Text and menus

| Button | Action |
| --- | --- |
| A / B | Next page (a small ▼ blinks when there is more) |
| + pad up/down | Move in a menu or question |
| + pad left/right | Change a setting in a menu that shows values |
| A | Choose |
| B / START | Leave the menu |

## At the pond ("Sit and listen")

Face the water and press A.

| Button | Action |
| --- | --- |
| + pad | Move the cursor over the 8 × 5 pond |
| A | With the **Pebble**: drop a pebble — a note at that row, and a new ripple. With a **lily** tool: place it; on a lily of the same kind, lift it out; on a different lily, replace it. Stones can't be moved. |
| B | Change what you hold: Pebble → Bell → Reed → Root → Wood (only the ones you've discovered) |
| SELECT | Just listen: hides the cursor and words. Any button brings them back. |
| START | The pond's settings (left/right to change): Scale, Density, Tempo, Wind, Rain, Echo, Water, Insects, Hold; post-game also Preset, Keep my pond, Load my pond; Clear lilies; Stand up / Title screen |

## Title screen

Up/down choose; A or START confirm. **Continue** appears when a save exists,
**Return to the pond** after the ending.
