# VACANT — Controls

## Walking

| Button | Action |
| --- | --- |
| D-pad | walk one paving stone at a time |
| B (hold) | walk twice as fast |
| A | ambient focus on/off: the city dims, nearby landmarks become louder, other voices step back |
| SELECT | Listening Mode on/off: the walker stands still, the city and the music carry on |
| START | open the synthesiser (pressed during a step, it opens when the step ends) |

## Synthesiser

| Button | Action |
| --- | --- |
| Up / Down | choose a setting |
| Left / Right | change the value (hold to repeat) |
| A | confirm, toggle or perform (edit seed, save, load, freeze, randomise, defaults) |
| SELECT | next page: MIX, TONE, EVOLVE, WORLD, MEMORY |
| START or B | close |

### Seed entry (WORLD page, SEED)

| Button | Action |
| --- | --- |
| A | start editing / travel to the typed seed |
| Left / Right | choose a digit |
| Up / Down | change the digit |
| B | cancel |

## Title screen

| Button | Action |
| --- | --- |
| START or A | begin |
| Left / Right | choose CONTINUE or NEW CITY (when a saved place exists) |
